# Cosminova Consulting

Marketing website for Cosminova Consulting, a Los Angeles-based cosmetics quality and regulatory consultancy.

## Structure

Static HTML/CSS/JS site, no build step required.

- `index.html` — Home
- `about.html` — About
- `services.html` — Services
- `contact.html` — Contact
- `404.html` — Custom not-found page
- `assets/css/style.css` — Site styles
- `assets/js/main.js` — Mobile nav + active link handling
- `assets/img/` — Logo, favicon, and icon assets

## Local preview

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Deployment

Deployed via GitHub Pages from the `main` branch root.
